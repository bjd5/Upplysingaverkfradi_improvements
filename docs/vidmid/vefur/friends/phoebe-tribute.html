Phoebe tribute

Ein ytri heimild til samanburðar

Tölfræðin annars staðar á síðunni kemur úr handritunum sjálfum. Hér er bætt við einni óháðri heimild: TMDB (The Movie Database), sem staðfestir hver leikur Phoebe og í hversu mörgum þáttum.

(TMDB-samantekt vantar — staðbundin tímamæling án lykils.)

Bæði talan og samanburðurinn við handritagreininguna koma úr keyrslunni sjálfri: src/fetch_tmdb.py skrifar textareitinn hér að ofan út frá því sem TMDB svaraði. Sæki þjónustan annan þáttafjölda síðar breytist munurinn með, án þess að nokkur þurfi að muna eftir að laga setninguna.

Hvaða þjónusta og hvers vegna

TMDB API var valið því það er ókeypis, vel skjalfest og krefst aðgangslykils — sem er einmitt æfingin í þessum hluta verkefnisins. Öll köll fara í gegnum src/fetch_tmdb.py.

Atriði Svar
Þjónusta TMDB (The Movie Database) API v3
Skjölun https://developer.themoviedb.org/reference/tv-series-details
Opin eða krefst auðkenningar Krefst auðkenningar — Authorization: Bearer <token> á hverri beiðni
Hvernig fæst aðgangur Ókeypis reikningur á themoviedb.org → Settings → API → tekur út “API Read Access Token” (v4 auth, langur JWT-strengur)
Endapunktar kallaðir GET /3/tv/1668?language=en-US og GET /3/tv/1668/aggregate_credits?language=en-US (1668 = TMDB-auðkenni Friends)
Færibreytur sendar language=en-US á báðum köllum; engar aðrar — engin persónuleg gögn fara út
Hvenær sótt Sjá “Sótt” tímastimpilinn í reitnum hér að ofan — hann er skrifaður sjálfkrafa í hverri keyrslu
Hluti svars sem er notaður name/number_of_episodes/first_air_date úr sýningarsvarinu; roles[].character, name, profile_path og total_episode_count fyrir manneskjuna sem leikur “Phoebe Buffay” úr leikarasvarinu

Hvernig lykillinn er lesinn án þess að fara í Git

src/fetch_tmdb.py les TMDB_TOKEN í þessari röð:

  1. Umhverfisbreytan TMDB_TOKEN (þetta er leiðin sem GitHub Actions notar — sjá næst).
  2. Ef hún er ekki sett: staðbundin .env-skrá í rót repo-sins.

.env er í .gitignore (.env og .env.*) og hefur aldrei verið í Git-sögu þessa repo-s. .env.example er hins vegar committed og sýnir hvaða breytu þarf, án gildis — sniðmátið sem hver liðsmaður afritar staðbundið:

cp .env.example .env
# opna .env og setja inn eigin TMDB_TOKEN
python src/fetch_tmdb.py --contact "GitHub: notandanafn"

Skriftan neitar að keyra ef TMDB_TOKEN vantar eða er enn sniðmátsgildið replace_with_your_tmdb_token, með skýrum villuboðum sem vísa á hvar lykilinn er sóttur.

Hvernig GitHub Pages byggir síðuna án þess að lykillinn fari í Git

.env er eingöngu staðbundin skrá — hún fer aldrei í GitHub Actions. Í staðinn er TMDB_TOKEN skráð sem GitHub Actions leyndarmál (Settings → Secrets and variables → Actions → New repository secret, nafn TMDB_TOKEN, gildi = sama “API Read Access Token”).

.github/workflows/pages.yml sækir gögnin ferskt í hverri byggingu — nákvæmlega sama mynstur og phoebe_analysis.py og phoebe_central_perk.py nota nú þegar fyrir handritagreininguna — og les lykilinn úr leyndarmálinu:

- name: Fetch TMDB data
  env:
    TMDB_TOKEN: ${{ secrets.TMDB_TOKEN }}
  run: python src/fetch_tmdb.py --contact "GitHub: ${{ github.repository }}"

Hvorki data/processed/tmdb/phoebe-tmdb.json né site/_generated/phoebe-tmdb-summary.md eru í Git (sama regla og gildir um phoebe-stats og hina Central Perk-greininguna): þau eru afleidd og verða til upp á nýtt í hverri keyrslu, bæði staðbundið og í CI. Lykillinn sjálfur endar aldrei í neinni af þessum skrám — aðeins nafn leikkonu, mynd-slóð og þáttafjöldi eru vistuð.
